# NovaMotion Live Tab

> A modern, ultra-lightweight, and privacy-first Chrome New Tab extension with local live wallpapers, 3D iPhone-style depth parallax, multiple calendar systems, smart notes, shortcuts, and an instant live customization engine.

---

## ✨ Features

- 🎥 **Live Video Wallpapers**: High-performance MP4/WebM decoding stored 100% locally via IndexedDB.
- 🖼 **Image & GIF Support**: Smooth transitions and instant asset rendering.
- 📱 **iPhone-Style Depth & Parallax**: Layered perspective depth with smooth Lerp interpolation and zero-idle CPU overhead.
- 📅 **Multi-Calendar Engine**: Gregorian, Persian (شمسی), Islamic, Hebrew, Japanese, Chinese, and Indian National systems.
- 📝 **Smart Quick Notes**: Auto-saving local notepad.
- ⏱ **Pomodoro Focus Suite**: Configurable focus and break timers with overlay dimming.
- 🎨 **Visual Engine Controls**: Real-time Brightness, Contrast, Saturation, Hue Rotation, and Sepia tuning.
- 📐 **Absolute Freedom Layout**: Freely reposition clock, calendar, and search bar with percentage-based responsive coordinates.
- 🪄 **Pixel-Perfect Live Preview**: Scaled virtual canvas with real-time responsive simulation (16:9, Ultrawide, Windowed).

---

## 🚀 Installation

1. Download the latest release from the [Releases](https://github.com/amiraction0938/NovaMotion-Live-Tab/releases) section.
2. Unzip the downloaded archive.
3. Open Google Chrome and navigate to `chrome://extensions/`.
4. Enable **Developer mode** in the top-right corner.
5. Click **Load unpacked** and select the folder containing `manifest.json`.
6. Open a new tab and enjoy **NovaMotion**.

---

## 🔒 Privacy & Architecture

- **100% Local Storage**: Wallpapers, sounds, and notes never leave your machine.
- **Zero Tracking**: No telemetry, analytics, or external API dependencies.
- **Manifest V3 Compliant**: Built strictly following Chromium's modern security and performance guidelines.
